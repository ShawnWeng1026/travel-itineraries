# Travel Itineraries

個人旅行手帖。目前收錄：2026 九州福岡 6 天 5 夜親子慢遊（V1.9）。

## 使用

以瀏覽器直接開啟 `index.html`；不需要安裝套件、建置工具、後端或資料庫。
HTML、CSS、JavaScript、主視覺照片均包含在單一檔案。Google Fonts 為選用，無網路時使用本機備援字體；Google Maps 導航及官方資訊連結需要網路。

唯一文字主檔位於旅行專案的 `working/202611_福岡_V1.9.md`；`index.html` 的 `TRIP` 是經隱私篩選的衍生輸出，不應直接修改。勾選進度只儲存在使用者瀏覽器的 localStorage，不會上傳或跨裝置同步。

## 發布

GitHub Pages：Deploy from a branch → `main` → `/ (root)`。

日常更新使用獨立 `feature/*` 分支，驗證後 Commit、Push 並建立 PR；待 Review 後合併，沿用既有 Pages 發布。禁止直接推送 main 或使用一次性初始部署程式。

完整本機規範見父層 PROJECT.md；本 Repository 不包含原稿與 PDF 的版本歷史。Web 為 V1.9、修訂 2026/10/26；離線 PDF 仍為原 V1.9，尚未同步航班／住宿已確認及 15:00 入住、11:00 退房規定。

此 Repository 只存放公開網站；不包含訂房憑證、原稿、座位編號、私人聯絡資料或任何認證。
